# App Técnicos de Aire Acondicionado — Frontend

Frontend estático (HTML/CSS/JS) con separación de responsabilidades por capas.
Se despliega en GitHub Pages.

## Estructura

- `frontend/`   → aplicación cliente
- `docs/`       → documentación técnica

## Configuración

1. Editar `frontend/assets/js/config.js` y colocar la URL del Web App
   de Apps Script (backend, gestionado por separado).
2. Publicar la carpeta `frontend/` en GitHub Pages.
